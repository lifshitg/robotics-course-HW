# HW2 figures

`rooms.png` shows the physical (uninflated) rooms, robot and goal. Rebuild it from
the same layout definitions used by Gazebo and the raw map:

```bash
python3 tools/build_hw02_assets.py
```

Run from the repository root. No route, configuration-space solution or reference
planner is included in this figure. Student planning figures belong in their
submitted work; instructor planning figures stay under ignored `build/`.
