# HW1 shared environment

This folder will contain the environment used by student code in `../my_solution/`
and the instructor's local reference implementation in `../ta_solution/`.

No runnable environment has been configured yet. Before release, add:

- Supported operating system and pinned ROS 2 and Gazebo versions.
- Dependency installation instructions or a container configuration.
- Robot model, simulation world, and camera configuration.
- Topic names, message types, coordinate frame names, and command interfaces.
- A documented method for obtaining a 3D target position.
- Simulation launch commands and commands for running either implementation.
- A basic environment check students can run before implementing the assignment.

Keep shared dependencies and simulation assets here rather than duplicating them
in the implementation folders.
