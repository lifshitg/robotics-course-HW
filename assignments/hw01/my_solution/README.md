# Your HW1 solution

Complete and submit your HW1 work in this folder. It is tracked by Git.

The assignment is currently a scaffold. Starter code with TODOs and the expected
package structure will be added before release.

Use the shared environment in `../environment/` and follow `../instructions.md`.
Add your short report as `report.md`, including the demonstration link and any
instructions needed to run your implementation.

Commit source files and the report. Do not commit generated build output, local
virtual environments, or large simulation recordings.
